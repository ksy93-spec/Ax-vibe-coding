# 디자인 토큰

`tokens.css` 하나가 전부입니다. 값을 CSS 변수로만 정의하고 컴포넌트 스타일은 넣지 않습니다.
컴포넌트는 킷별 `app.css` 에서 이 변수를 참조합니다.

## 정하고 들어간 것

- 본문 기본값은 14px(`--text-md`)입니다. 사내 업무 도구는 한 화면에 정보가 많아 16px가 크게 느껴집니다.
- 행간을 라틴 기준보다 넉넉하게 잡았습니다(`--leading-normal: 1.65`). 한글은 1.5 아래로 내리면 답답해집니다.
- 자간을 `-0.003em` 으로 살짝 조였습니다. Pretendard 기본 자간이 한글 문단에서 약간 벌어져 보입니다.
- 색은 라이트와 다크 두 벌입니다. 시스템 설정을 따르고, `<html data-theme="dark">` 로 덮어쓸 수 있습니다.
- 명도 대비는 본문과 배경이 WCAG AA를 넘도록 잡았습니다. `--c-fg-subtle` 은 보조 텍스트 전용이라 본문에 쓰지 마세요.

## 사내 모델에게 시킬 때

"색을 정해줘"라고 시키지 마세요. 임의의 hex 값을 만들어 냅니다. 대신 이렇게 지시합니다.

```
색상과 간격은 tokens.css 의 CSS 변수만 사용할 것.
새 hex 값이나 rgb 값을 쓰지 말 것. 필요한 변수가 없으면 코드를 쓰지 말고 물어볼 것.
```

## 브랜드 색 교체

사내 CI 색이 있으면 `--c-accent`, `--c-accent-hover`, `--c-accent-bg` 세 개만 바꾸면 됩니다.
`--c-accent-bg` 는 accent를 배경으로 깐 옅은 색이라 명도만 올려서 만듭니다.
