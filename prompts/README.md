# 사내 모델에 넘기는 프롬프트

사내 모델(ChatGPT Enterprise, Cline + Qwen)은 이 도구가 누구를 위한 것인지, 폐쇄망에서 무엇이 안 되는지 모릅니다.
"메모장에 받아쓰기 넣어 줘" 라고만 하면 인터넷이 필요한 음성 인식을 끌어오거나, 작은 글씨 단추를 만듭니다.
여기 프롬프트는 이미 정해진 것과 합격 기준을 먼저 알려 줍니다.

| 파일 | 언제 |
| --- | --- |
| `00-project-instructions.md` | 처음 한 번. ChatGPT 프로젝트 지침에 붙여 넣습니다 |
| `10-screen-change.md` | 단추나 화면을 더하거나 바꿀 때 |
| `20-fix-error.md` | 테스트 실패, 콘솔 오류가 났을 때 |

## ChatGPT Enterprise

1. 프로젝트를 만들고 지침(Instructions)에 `00-project-instructions.md` 의 코드 블록을 붙여 넣습니다.
2. 프로젝트 파일로 `MANIFEST.md`, `types/memo.d.ts` 를 올립니다.
3. 대화마다 10, 20 중 하나를 골라 빈칸(〈 〉)을 채워 붙여 넣고, 고칠 파일 전체를 같이 붙여 넣습니다.

## Cline

10, 20 의 본문을 그대로 붙여 넣습니다. 파일은 Cline 이 직접 엽니다. 규칙은 `.clinerules` 에서 읽습니다.

## 공통 요령

- 한 번에 파일 하나. 여러 파일을 한꺼번에 시키면 앞 파일 내용을 잊고 서로 안 맞는 코드를 줍니다.
- `src/core.js` 를 고쳤으면 `tests/index.html` 을 열어 전부 통과하는지 봅니다.
- 쓰시는 분의 이름, 연락처, 병원 기록 같은 메모 내용은 어떤 모델에도 붙여 넣지 않습니다.
