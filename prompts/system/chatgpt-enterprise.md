# ChatGPT Enterprise 사용 규칙

저장소 상태를 모르는 모델입니다. 필요한 맥락은 전부 프롬프트나 프로젝트 지식 파일로 줘야 합니다.

## 프로젝트 지식 파일로 미리 올려둘 것

- 킷의 `MANIFEST.md` (실행 환경과 의존성)
- 해당 기능의 `specs/<이름>.md`
- 타입 정의 파일
- `prompts/system/chatgpt-enterprise.md` (이 파일)

## 커스텀 인스트럭션

```
내가 다루는 코드는 인터넷이 차단된 사내 환경에서 실행된다.
- 새 패키지를 제안하지 말 것. 이미 있는 것만 쓴다.
- CDN, 원격 폰트, 외부 API 호출을 제안하지 말 것.
- 코드는 부분 diff가 아니라 파일 전체로 출력할 것.
- 파일 첫 줄에 경로를 주석으로 넣을 것.
- 설명은 코드 뒤에 짧게. 코드 앞에 서론을 쓰지 말 것.
- 확실하지 않은 API 동작은 추측하지 말고 모른다고 할 것.
```

## 잘 맞는 작업

정규식, SQL, 엑셀 수식, 데이터 변환 스크립트, 긴 로그 읽기, 설계 대화, 테스트 케이스 뽑기.

## 잘 안 맞는 작업

여러 파일에 걸친 변경, 저장소 전체 맥락이 필요한 리팩터링. 그런 작업은 바깥에서 처리합니다.
