# Qwen 3.5-Cline 기본 규칙

`.clinerules` 파일로 저장소 루트에 두고 씁니다. 매 프롬프트에 반복하는 것보다 잘 지켜집니다.

```
이 저장소는 인터넷이 차단된 환경에서 실행됩니다.

금지:
- 패키지 설치 명령 (npm install, pip install, npx)
- 원격 URL 참조 (CDN, 폰트, 이미지, API 문서)
- package.json 의 의존성 목록 수정
- 요청받지 않은 파일 열기 또는 수정
- 요청받지 않은 리팩터링, 이름 변경, 포맷 변경

지켜야 할 것:
- 한 번에 한 파일만 수정한다
- 기존 함수 시그니처와 타입을 바꾸지 않는다
- TODO(사내) 주석이 붙은 부분만 채운다
- 수정 후 무엇을 바꿨는지 세 줄 이내로 요약한다
- 확신이 없으면 코드를 쓰지 말고 질문한다

파일 구조와 타입은 types/ 와 specs/ 에 이미 확정되어 있다. 참고만 하고 수정하지 않는다.
```

## 쓰면서 주의할 점

- 자동 승인을 끄고 diff를 확인합니다. 멀쩡한 코드가 조용히 사라지는 경우가 있습니다.
- 대화가 길어지면 결과가 나빠집니다. 파일 하나를 끝내면 새 대화를 엽니다.
- "개선해줘" 같은 열린 요청은 피합니다. 무엇을 어떻게 바꿀지 문장으로 지정합니다.
