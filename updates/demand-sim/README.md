# demand-sim 업데이트

킷을 한 번 통째로 옮긴 뒤에는 여기 zip 만 받아서 적용합니다. 위에서부터 순서대로 적용합니다.
GitHub 에서 zip 파일을 누르고 다운로드 단추(Download raw file)로 받으면 저장소 전체를 받지 않아도 됩니다.

적용 방법: zip 을 풀고 안의 `apply.bat` 을 실행합니다. zip 안에 킷 파일이 `files/` 아래 들어 있어 압축만 풀어서는 바로 쓸 수 없습니다.

- 처음이면 맨 위 처음 판 zip 의 `apply.bat` 을 실행합니다. `demand-sim` 폴더가 없으면 새로 만듭니다.
  탐색기 "압축 풀기" 로 `demand-sim-2026.10.01.1` 폴더가 생겼다면 그 옆에, 아니면 `apply.bat` 과 같은 폴더 안에 생깁니다.
- 그다음 판부터는 `apply.bat` 이 `demand-sim` 폴더를 자기와 같은 폴더 안, 옆, 한두 단계 위에서 찾습니다.
  못 찾으면 탐색기에서 `demand-sim` 폴더를 검은 창으로 끌어다 놓으라고 묻습니다.
- 판이 맞지 않으면 아무것도 바꾸지 않고 멈춥니다. 위에서부터 순서대로 적용합니다.

지금 가진 판은 킷 폴더의 `VERSION` 파일에 적혀 있습니다. 파일이 없으면 처음 판입니다.
