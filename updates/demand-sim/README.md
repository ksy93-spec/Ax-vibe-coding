# demand-sim 업데이트

## 가장 쉬운 방법: 통째로 바꾸기

[demand-sim-latest.zip](demand-sim-latest.zip) 은 항상 최신 판 전체입니다 (3MB). 깃헙에서 이 파일을 열고 다운로드 단추(Download raw file)로 받습니다.

1. 기존 `demand-sim` 폴더를 지웁니다 (또는 `demand-sim_old` 로 이름을 바꿔 둡니다).
2. zip 을 풀면 `demand-sim` 폴더가 생깁니다. 그 안의 `index.html` 을 Chrome 이나 Edge 로 엽니다.

끝입니다. 스크립트도, 순서도 없습니다. 지금 가진 판은 폴더 안 `VERSION` 파일에 적혀 있습니다.

잃는 것이 없는 이유: 시나리오와 설정은 브라우저(자동 저장)와 "작업 저장" 으로 받은 `.json` 파일에 있고, 킷 폴더에는 들어 있지 않습니다. 판매 실적 CSV 도 폴더 밖에 두세요.
단, 사내에서 킷 파일(`src/` 등)을 직접 고쳤다면 폴더를 지우기 전에 고친 파일을 따로 복사해 두세요.
