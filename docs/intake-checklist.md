# 반입 전 체크리스트

압축하기 전에 확인합니다. 한 항목이라도 걸리면 보안 심사에서 반려되거나 사내에서 실행이 안 됩니다.

## 네트워크 의존

- [ ] 소스 전체에 `http://`, `https://` 로 시작하는 런타임 로드가 없는가 (`grep -rn "https\?://" --include=* .`)
- [ ] `<link href="https://fonts.googleapis.com">` 같은 원격 폰트가 없는가
- [ ] `package.json` 스크립트에 `npx`, `npm i`, `curl`, `wget` 이 없는가
- [ ] 텔레메트리를 보내는 패키지가 없는가 (Next.js, Sentry 등은 기본으로 켜져 있습니다)

## 의존성

- [ ] 모든 버전이 정확한 버전으로 고정되어 있는가
- [ ] `vendor/` 안의 tarball/wheel 목록이 lock 파일과 일치하는가
- [ ] 오프라인 설치를 실제로 검증했는가 (`npm ci --offline`, `pip install --no-index`)
- [ ] Node/Python 버전이 사내 런타임과 맞는가

## 라이선스

- [ ] `MANIFEST.md`에 모든 의존성의 SPDX 식별자가 적혀 있는가
- [ ] GPL/AGPL 계열이 섞여 있지 않은가. 사내 도구라도 심사에서 문제가 됩니다.
- [ ] 폰트 라이선스를 확인했는가. 본문용은 OFL 계열(Pretendard, Noto Sans KR)이 안전합니다.
- [ ] 라이선스 원문 파일을 킷 안에 포함했는가

## 파일

- [ ] 경로에 한글, 공백, 특수문자가 없는가
- [ ] 인코딩 UTF-8, 줄바꿈 LF인가
- [ ] 압축 크기가 반입 한도 안인가
- [ ] `.env`, 토큰, 키, 개인 정보가 들어 있지 않은가
- [ ] 심볼릭 링크가 없는가 (전송 중 깨지거나 심사에서 반려됩니다)

## 문서

- [ ] `OFFLINE.md`에 적힌 절차만 따라 하면 인터넷 없이 실행되는가
- [ ] `PROMPT.md`가 사내 모델에 그대로 붙여넣을 수 있는 상태인가
