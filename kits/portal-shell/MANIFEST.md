# portal-shell

Market Intelligence 통합 포탈. 여러 사람이 각자 만든 기능의 결과를 한 화면에 모읍니다.

## 실행 환경

- 브라우저: Chromium 기반(Chrome, Edge) 또는 Firefox. `index.html` 더블클릭으로 실행됩니다.
- Node: 불필요
- Python: 모듈 데이터를 내보낼 때만 필요 (3.8 이상, 표준 라이브러리만)
- 빌드 단계: 없음

## 반입 방식

C. npm 의존성이 0개입니다. 반입되는 것은 소스 텍스트와 폰트 파일 하나입니다.

## 이 킷이 대신 해결해 둔 것

- **`file://` 에서 모듈을 동적으로 불러옵니다.** 로컬 JSON 을 `fetch` 로 못 읽는 제약을
  `<script>` 주입으로 우회합니다. 모듈을 추가할 때 포탈 코드를 고칠 필요가 없습니다.
- **모듈 하나가 깨져도 나머지는 뜹니다.** 없는 모듈은 건너뛰고, 계약을 어긴 모듈은
  무엇이 잘못됐는지 화면에 적어 줍니다.
- **차트 색이 검증되어 있습니다.** 색맹 시뮬레이션과 배경 대비를 자동 검사기로 통과시킨
  8색 순서입니다. 순서를 바꾸거나 색을 추가하면 이 보장이 깨집니다.
- **모든 차트에 표 보기가 붙어 있습니다.** 라이트 모드에서 일부 계열 색이 흰 배경 대비
  3:1 미만이라 필수입니다.
- **키보드로도 값을 읽습니다.** 차트에 포커스를 두고 좌우 방향키를 누르면 마우스 호버와
  같은 내용이 나옵니다.
- **갱신이 오래된 모듈을 표시합니다.** 7일이 지나면 사이드바와 카드에 며칠 전인지 나옵니다.
- **`</script>` 문자열을 이스케이프합니다.** 데이터에 이 문자열이 들어가면 HTML 파서가
  스크립트를 거기서 끊어 화면이 통째로 비는데, 내보내기 단계에서 막습니다.

## 차트 형식을 고를 때

- 값이 하나면 차트를 만들지 말고 지표 카드(`kpis`)를 쓰세요. 막대 하나짜리 차트는 읽히지 않습니다.
- **자릿수가 다른 값을 한 차트에 넣지 마세요.** 축을 두 개 쓰는 건 답이 아닙니다.
  같은 기준으로 지수화하거나(첫 달 = 100), 차트를 나누세요.
  `data/price_monitor/data.js` 가 지수화한 예시입니다.
- 계열은 최대 8개입니다. 더 필요하면 "기타"로 묶거나 차트를 나눕니다.
