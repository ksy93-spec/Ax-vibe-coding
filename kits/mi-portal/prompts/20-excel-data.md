# 예시 데이터를 엑셀로 바꾸기

화면이 `src/data/mi-sample.js` 의 예시 숫자 대신 사용자가 고른 엑셀 파일을 읽게 합니다.
포탈은 서버가 없으므로 파일은 사용자가 "엑셀 가져오기" 로 직접 고릅니다. 읽은 내용은 그 PC 에 저장됩니다.

```
〈화면 이름〉 화면이 엑셀 파일을 읽어 쓰게 바꾼다. 프로젝트 지침의 규칙을 따른다.
src/features/orders/ 의 가져오기 방식과 같게 만든다 (orders-import-dialog.tsx, data/schema.ts, data/store.ts).

[엑셀 모양]
- 시트: 첫 시트
- 첫 행 머리글: 〈예: 월, 고객사, 품목, 매출액, 계획〉
- 예시 행: 〈예: 2026-01, 고객 A, 브레이크 모듈, 120000000, 110000000〉
  (실제 사내 숫자는 넣지 말고 모양만 알 수 있는 가짜 값으로 쓴다)

[검증 규칙]
- 〈예: 월은 YYYY-MM, 매출액과 계획은 0 이상 숫자, 고객사와 품목은 비면 안 됨〉
- 틀린 행은 건너뛰고 "N행: 사유" 로 보여 준다. 사유는 한국어.
- 엑셀 날짜 칸은 Date 로 들어오므로 문자열로 바꿔서 검증한다.

[저장]
- zustand + persist, localStorage 이름 'mi-portal:〈영문이름〉'
- 처음에는 예시 데이터로 시작하고, 가져오기에서 "이 파일로 바꾸기" 와 "기존 목록에 더하기" 를 고를 수 있다.

[이번에 줄 파일]
〈한 개: data/schema.ts → data/store.ts → components/〈이름〉-import-dialog.tsx → 화면 파일 수정 순서〉

[합격 기준]
npm run check, npm run build:single 통과.
머리글이 다른 파일, 빈 행, 숫자 칸에 글자가 있는 파일을 넣어도 화면이 깨지지 않고 사유가 보인다.
```
