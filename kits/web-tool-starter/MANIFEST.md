# web-tool-starter

브라우저에서 바로 열리는 사내 도구 뼈대. 빌드 단계와 패키지 설치가 없습니다.

## 실행 환경

- Node: 불필요
- Python: 불필요 (선택: 로컬 서버로 열 때만)
- 브라우저: Chromium 기반 (Chrome, Edge) 또는 Firefox. `file://` 로 직접 열립니다.
- 빌드 단계: 없음

## 반입 방식

C. npm 의존성이 0개입니다. 반입되는 것은 소스 텍스트와 폰트 파일 하나뿐입니다.

## 포함된 의존성

npm 패키지 없음. 아래는 코드가 아닌 자산입니다.

| 파일 | 출처 | 버전 | 라이선스(SPDX) | 원문 |
| --- | --- | --- | --- | --- |
| `assets/fonts/PretendardVariable.subset.woff2` | Pretendard (Kil Hyung-jin) | 1.3.9 서브셋 | OFL-1.1 | `assets/fonts/Pretendard-OFL.txt` |

폰트는 587KB 가변 woff2 입니다. 한글 음절 2,780자와 라틴, 문장부호, 원문자, 도형 기호를 담았고
한자는 빠져 있습니다. 굵기는 45~930 연속입니다.

## 이 킷이 대신 해결해 둔 것

폐쇄망에서 직접 부딪히면 시간을 잡아먹는 것들입니다.

- CP949(EUC-KR) 로 저장된 CSV 자동 판별. 사내 시스템에서 내려받은 파일 상당수가 CP949 입니다.
- 내보낼 때 UTF-8 BOM 부착. BOM 이 없으면 엑셀에서 한글이 전부 깨집니다.
- 따옴표 안의 쉼표와 줄바꿈 처리. 직접 `split(',')` 로 짜면 여기서 데이터가 밀립니다.
- ES 모듈 대신 클래식 스크립트. `file://` 로 열 때 ES 모듈은 CORS 로 막힙니다.
- 다운로드 파일명에서 한글 제거. 크로미움은 `<a download>` 에 한글이 섞이면 이름을 통째로
  버리고 확장자 없는 `download` 파일을 떨굽니다.
- 한글 본문 행간과 자간 조정.
