# xlsx-automation

엑셀과 CSV 를 읽어 가공하고 서식 있는 보고서로 내보내는 파이썬 킷.

## 실행 환경

- Python: 3.8 이상. 사내 표준 파이썬이면 됩니다.
- Node: 불필요
- 빌드 단계: 없음
- OS: Windows, macOS, Linux 어디서나 됩니다. 아래 휠이 전부 순수 파이썬입니다.

## 반입 방식

B. `vendor/` 에 휠 파일을 담았고 오프라인 설치합니다.

두 휠 모두 `py3-none-any` 라 파이썬 버전과 CPU 아키텍처를 가리지 않습니다.
바이너리 휠(lxml, numpy, pandas 같은 것)은 파이썬 버전과 플랫폼이 정확히 맞아야 해서
폐쇄망 반입이 까다롭습니다. 이 킷은 그 문제를 피하려고 순수 파이썬만 씁니다.

## 이 킷이 대신 해결해 둔 것

- CP949(EUC-KR) CSV 자동 판별. 바이트 추측이 아니라 실제 디코딩을 시도해서 어긋나지 않습니다.
- CSV 내보낼 때 UTF-8 BOM 부착. BOM 이 없으면 엑셀이 CP949 로 읽어 한글이 전부 깨집니다.
- 한글 열 너비 계산. 엑셀 너비 단위가 영문 기준이라 한글 열은 그냥 두면 잘립니다.
- 시트 이름 제약 처리. 31자 제한과 `[ ] : * ? / \` 금지, 잘려서 겹치는 이름 회피.
- `"1,234"`, `"(1,200)"`, `"3400원"` 같은 문자열 숫자 변환.
- `2024.03.05`, `20240305`, `2024년 3월 5일` 같은 날짜 표기 변환.
- 열 구성이 다른 파일을 합칠 때 열이 사라지지 않게 합집합으로 처리.
- 큰 xlsx 를 `read_only` 로 읽어 메모리 절약.

## 알려진 제약

Word 문서(.docx) 자동화는 들어 있지 않습니다. `python-docx` 가 `lxml` 을 필요로 하는데
`lxml` 은 바이너리 휠이라 파이썬 버전과 OS 아키텍처를 정확히 맞춰야 합니다.
필요하면 사내 파이썬의 `python -V` 결과와 64비트 여부를 알려 주세요. 맞는 휠로 다시 만들겠습니다.
