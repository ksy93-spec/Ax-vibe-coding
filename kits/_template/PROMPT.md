# 사내 모델용 프롬프트

## Qwen 3.5-Cline (VS Code)

작업을 시작하기 전에 `.clinerules` 가 저장소 루트에 있는지 확인하세요.

각 작업마다 아래 틀로 요청합니다. 한 번에 한 파일만 다룹니다.

```
파일: src/<경로>
목표: <함수 하나 또는 화면 하나>

이미 정해진 것 (바꾸지 말 것):
- 타입: types/<파일>.d.ts 의 <타입명>
- 함수 시그니처: <시그니처>
- 이 파일 밖은 수정하지 말 것

할 일:
- <TODO(사내) 주석이 붙은 부분만 채울 것>

금지:
- 새 패키지 설치
- 원격 URL 사용
- 다른 파일 열기 또는 수정

완료 기준:
- <체크리스트 또는 테스트 이름>
```

## ChatGPT Enterprise

프로젝트 지식 파일로 먼저 올릴 것: `MANIFEST.md`, `specs/<이름>.md`, 타입 정의 파일.

```
아래는 폐쇄망에서 돌아가는 사내 도구의 파일 하나입니다.
인터넷 접근이 없고 새 패키지를 설치할 수 없습니다.

[파일 전체 붙여넣기]

요청: <구체적 변경 사항 하나>
제약: 기존 함수 시그니처와 import 목록을 바꾸지 말 것
출력: 수정된 파일 전체. 설명은 파일 뒤에 세 줄 이내.
```
