# 설치와 실행

설치할 것이 없습니다. 인터넷도 필요 없습니다.

## 1. 압축 해제

한글과 공백이 없는 짧은 경로에 풉니다. 예: `C:\work\demand-sim`

## 2. 실행

`index.html` 을 Chrome 이나 Edge 로 엽니다(더블클릭). 처음이면 데이터 탭의 "예시 데이터로 시작" 을 누르세요.

`serve.bat` 은 로컬 서버로 열어야 할 때만 씁니다. 이 도구의 기능은 전부 `file://` 에서 동작합니다.

## 3. 확인

- [ ] `tests/index.html` 을 열면 "19/19 통과" 가 나온다
- [ ] 글꼴이 맑은 고딕이 아니라 Pretendard 로 보인다
- [ ] 예시 데이터로 시작하면 관측 브랜드 12개와 기준선 표가 나온다
- [ ] 결과 탭에서 "불확실성 구간 계산" 을 누르면 몇 초 안에 차트에 띠가 생긴다
- [ ] 보고서 탭의 "인쇄 / PDF" 로 A4 미리보기가 나온다
- [ ] 브라우저 콘솔(F12)에 빨간 오류가 없다

## 문제가 생기면

**화면이 비어 있고 콘솔에 `App is not defined` 또는 `Cannot read properties of undefined`**
`index.html` 의 스크립트 순서가 바뀌었습니다. `src/lib/dom.js` 가 맨 앞, `src/main.js` 가 맨 뒤입니다.

**사내 CSV 를 넣었더니 "열 지정 필요"**
열 이름이 목록에 없습니다. 데이터 탭에서 빨간 칸의 열을 고르면 됩니다. 자주 쓰면 `prompts/10-column-names.md`.

**지난번 시나리오가 사라졌다**
브라우저 자동 저장은 사내 정책으로 막힐 수 있습니다. 작업이 끝나면 "작업 저장" 으로 `.json` 을 받아 두세요.

**결과가 이상하다**
데이터 탭 맨 아래 "데이터 점검" 과 시나리오 탭의 카드 "점검" 표시를 먼저 보세요. 재현 방법을 사내 정보 없이 정리해 바깥 저장소로 넘기면 명세부터 고칩니다.
