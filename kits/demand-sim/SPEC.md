# 권역별 수요 시뮬레이터 명세

## 1. 한 줄 요약

지역 x 브랜드 x 파워트레인 단위로 향후 24개월 월 판매를 예측하고, 외생변수(보조금, CO2 규제, 자율주행 규제 등)를 강도와 기한을 정한 카드로 얹어 시나리오별 판매와 점유율 변화를 보고서로 내는 HTML 도구.
브랜드별 대당 디스플레이 수와 우리 공급 비중을 넣으면 지역별 디스플레이 수요(TAM)와 우리 점유율까지 이어서 계산합니다.

### 화면에 쓰는 말

쓰는 사람이 분석 전문가가 아니어도 읽히도록 화면에서는 아래처럼 풀어 씁니다. 코드와 이 문서는 왼쪽 말을 그대로 씁니다.

| 코드, 명세 | 화면 |
| --- | --- |
| 총수요, TIV | 시장 전체 판매 |
| 파워트레인 | 동력원 (전기차 BEV, 하이브리드 HEV 등) |
| 기준선 | 기본 전망 |
| 충격 카드, 층(TIV/POWERTRAIN/BRAND) | 변수 카드, "무엇이 바뀌나요?" (시장 전체 판매량 / 동력원 비중 / 브랜드 점유율) |
| 강도 최빈 / 최소 / 최대 | 예상 영향 / 작게 보면 / 크게 보면 |
| 발생 확률 | 일어날 가능성 |
| 도달 방식 step / linear / scurve | 반영 속도 바로 / 일정하게 / 천천히 시작해 빨라지게 |
| 유지 기간, 반감기 | 효과는? 계속 이어짐 / 일정 기간 뒤 사라짐 / 서서히 줄어듦 |
| 당겨쓰기 | 시작 전 미리 사는 수요 (막차 수요) |
| 몬테카를로, P10~P90 | 가능 범위 계산, 가능 범위 (10~90%) |
| 기여도, 상호작용 | 카드별 영향, 카드끼리 겹치는 효과 |
| 관측 브랜드 | 지켜볼 브랜드 |

## 2. 쓰는 사람과 상황

분석가가 시나리오를 만들고, 그 결과를 인쇄(PDF)와 CSV 로 보고합니다.
전 세계 총수요(TAM)는 범위가 너무 넓어 사업 영향을 정량화하기 어려우므로, 주요 지역 안의 점유율 변화로 범위를 좁힙니다.
관측 브랜드는 약 12개이고 나머지는 "기타" 하나로 묶어 총수요가 그대로 보이게 합니다.

## 3. 입력

### 3.1 월별 판매 CSV (필수)

| 표준 필드 | 알아보는 열 이름 (대소문자, 공백 무시) | 필수 | 예시 |
| --- | --- | --- | --- |
| month | Month, YYYYMM, Period, Date, 월, 기간, 년월 | 예 | 2026-08, 202608, 2026/8 |
| region | Region, Sales Region, 지역, 권역 | 예 | CN |
| country | Country, Sales Country, 국가 | 아니오 | DE |
| brand | Brand, Sales Brand, Make, OEM, 브랜드 | 예 | Brand A |
| units | Units, Volume, Sales Volume, Sales, Qty, 판매량 | 예 | 12,345 |

열 이름이 목록에 없으면 데이터 탭에서 열을 고릅니다. 자주 쓰면 `src/model/prep.js` 의 `ALIASES` 에 더합니다.

### 3.2 분기별 파워트레인 CSV (선택)

| 표준 필드 | 예시 |
| --- | --- |
| quarter | 2026-Q2, 2026Q2, 2Q26. 월을 넣으면 그 분기로 합칩니다 |
| region | CN |
| brand | Brand A |
| powertrain | BEV, PHEV, HEV, ICE (대문자로 정리) |
| units | 12,345 |

### 3.3 디스플레이 가정 CSV (선택)

화면에서 직접 넣어도 됩니다. 브랜드 행 하나에 지역 행을 더하면 그 지역에서는 지역 행이 우선합니다.

| 표준 필드 | 알아보는 열 이름 | 예시 |
| --- | --- | --- |
| brand | Brand, Sales Brand, OEM, 브랜드, 고객사 | Brand A |
| region | Region, 지역 (비우면 모든 지역) | CN |
| panels | Panels per vehicle, Displays, 대당 디스플레이 수, 탑재수 | 2.4 |
| share | Our share, Share, 우리 점유율, 공급 비중 | 25%, 25, 0.25 |

공급 비중은 사내 자료입니다. 작업 파일(.json)과 브라우저 자동 저장에 들어가므로 사내 PC 밖으로 내보내지 않습니다.

## 4. 계산

### 4.1 실적 정리

- 관측 브랜드에 없는 브랜드는 `기타` 로 합칩니다. 총합은 바뀌지 않습니다.
- 월별 브랜드 합계를 분기 파워트레인 비중으로 나눕니다. 분기 비중을 분기 가운데 달에 놓고 사이를 선형 보간한 값으로 시작해,
  월 합계와 분기별 파워트레인 합계를 둘 다 맞출 때까지 번갈아 비례 조정(IPF)합니다.
- 해당 분기 자료가 없으면 가장 가까운 분기 비중을, 브랜드 자료가 아예 없으면 같은 분기 지역 평균 비중을 씁니다. 데이터 점검에 비율이 나옵니다.

### 4.2 기준선

판매(i, p, r, h) = 총수요 TIV(r, h) x 파워트레인 비중 m(p | r, h) x 파워트레인 안 점유율 s(i | p, r, h)

- 총수요: 최근 12개월 계절 조정 평균 x (1 + 연간 성장률)^경과연수 x 계절 지수.
  계절 지수는 2x12 이동평균 비율의 달력 월 평균(실적 24개월 이상일 때). 성장률은 최근 12개월 / 직전 12개월(±30% 제한). 지역별로 덮어쓸 수 있습니다.
- 점유율: 최근 trendWindow 개월 로그 점유율의 기울기를 phi 로 감쇠시켜 이어 간 효용을 softmax 합니다. 수준은 최근 3개월 평균입니다.
- 최근 trendWindow 개월에 판매가 없는 항목은 비활성이며 예측에서도 0 입니다. 카드로 살릴 수 없습니다.

### 4.3 충격 카드

| 층 | 강도 단위 | 적용 |
| --- | --- | --- |
| TIV | % | 총수요 x (1 + 강도 x 발효강도) |
| POWERTRAIN | %p | 파워트레인 효용에 더함. 완전 발효 달에 그 달 기준 비중 + 강도 가 정확히 되는 값 |
| BRAND | 상대 % | 브랜드 효용에 더함. 완전 발효 달에 그 달 기준 점유율 x (1 + 강도) 가 정확히 되는 값. 같은 파워트레인 안에서 나눠 가짐 |

- 발효강도: 시작 월부터 도달 기간에 걸쳐 0 에서 1 (즉시, 선형, S자), 유지 기간 뒤 반감기로 감소. 유지가 "끝까지" 면 계속 1.
- 국가 한정: 지정 국가의 최근 12개월 지역 내 비중(브랜드 카드는 그 브랜드 기준)만큼 강도를 줄여 지역에 적용합니다.
- 당겨쓰기: 시작 전 K 개월 대상 물량 +pct%, 시작 후 K 개월에서 늘린 물량만큼 기존 물량 비례로 차감. 두 구간 합은 그대로입니다.
- 여러 카드는 효용에 합산되어 점유율 합이 항상 1 입니다.
- 브랜드 카드는 파워트레인 비중을 바꾸지 않습니다. 브랜드 사건이 전기차 수요 자체를 늘린다고 보면 파워트레인 카드를 따로 넣습니다.

### 4.4 불확실성과 기여도

- 시나리오 경로: 켜진 카드가 모두 최빈값으로 발생한다고 가정합니다.
- 구간: 카드마다 발생(확률)과 강도(최소, 최빈, 최대의 삼각분포)를 뽑아 N 번 계산한 P10, P50, P90. 시드 42 고정.
- 기여도: 카드 한 장만 켰을 때 기준선과의 차이. 전체 차이에서 카드별 합을 뺀 나머지를 상호작용으로 따로 보여 줍니다.

### 4.5 디스플레이 수요와 우리 몫

- 디스플레이 수요(장) = 차량 판매(대) x 대당 디스플레이 수
- 우리 몫(장) = 디스플레이 수요 x 그 브랜드 안 우리 공급 비중
- 지역과 전체의 우리 점유율 = 우리 몫 합 / 디스플레이 수요 합
- 가정이 없는 브랜드는 기본값(대당 2장, 비중 0%, 화면에서 바꿈)을 쓰고 표에 * 로 표시합니다.
- 시나리오로 차량 판매가 바뀌면 디스플레이 수요와 우리 몫도 같은 비율로 바뀝니다. 가정 자체(대당 수, 비중)는 시나리오가 바꾸지 않습니다.

### 4.6 지도

- 지도 경계: Natural Earth 1:110m (공공 저작물), Natural Earth 1 투영. 바깥에서 `scripts/build-worldmap.cjs` 로 만든 파일을 킷에 넣었습니다.
- 지역 -> 나라: 국가 열의 값(ISO2, ISO3, 영문, 한글 이름)을 먼저 찾고, 못 찾으면 지역 이름 별칭(NA, North America, 북미 등)을 씁니다. 국가 열이 없을 때 'NA' 는 나미비아가 아니라 북미입니다.
- 지도에 못 그린 지역은 지도 아래 단추로만 고릅니다. 별칭은 `src/model/geo.js` 의 `REGION_ALIASES` 에 더합니다.

## 5. 출력

### 5.1 결과 CSV (디스플레이 연동 기준)

UTF-8 BOM, 한 행이 시나리오 x 지역 x 브랜드 x 월입니다. 열 이름과 순서는 바꾸지 않습니다. 디스플레이 연동은 이 형식을 기준으로 붙입니다.

| 열 | 내용 |
| --- | --- |
| scenario | 시나리오 이름 |
| region | 지역 코드 또는 `전체` |
| brand | 관측 브랜드 또는 `기타` |
| month | YYYY-MM (예측 월) |
| baseline_units, scenario_units | 판매 대수 (정수) |
| p10_units, p50_units, p90_units | 결과 탭에서 구간을 계산한 시나리오만. 아니면 빈 칸 |
| baseline_share, scenario_share | 지역 총수요 대비 점유율 (0~1, 소수 6자리) |
| region_tiv_baseline, region_tiv_scenario | 지역 총수요 |
| baseline_panels, scenario_panels | 디스플레이 수요(장). 디스플레이 가정이 없으면 빈 칸 |
| our_panels_baseline, our_panels_scenario | 우리 몫(장). 디스플레이 가정이 없으면 빈 칸 |

새 열은 끝에만 더합니다. 2026.10.01.2 에서 마지막 네 열을 더했습니다.

### 5.2 작업 파일 (.json)

관측 브랜드, 기준선 설정, 시나리오와 카드, 보고서 설정. 판매 실적은 담지 않습니다. 형식은 `types/sim.d.ts` 의 `Sim.ProjectFile`.

### 5.3 보고서

요약표(중심 브랜드 x 지역), 지역별 월 판매 차트, 시나리오 가정(카드 내용과 근거), 카드별 영향, 방법 설명. 브라우저 인쇄로 PDF 를 만듭니다.

## 7. 예외 상황

| 상황 | 동작 |
| --- | --- |
| 필수 열을 못 찾음 | 열 지정 칸이 빨갛게 표시되고 계산하지 않음 |
| 읽지 못한 행 | 건너뛰고 행 수와 첫 행 번호를 알림 |
| 실적 24개월 미만 | 계절 지수 1, 자동 성장률 0. 경고 |
| 판매가 없는 대상의 카드 | 카드 표에 "오류", 계산에서 빼고 결과 탭에 경고 |
| 시작 월이 실적 기간 안 | "확인" 경고 (이중 계산 가능성) |
| 당겨쓰기 물량 > 차감 구간 물량 | 차감 구간을 0 으로 자르고 경고 |
| 작업 파일의 브랜드가 데이터에 없음 | 그 브랜드를 빼고 알림 |

## 8. 하지 않을 것

- 가격, 재고, 공급 제약 모델링. 필요하면 카드로 표현합니다.
- 회귀로 카드 강도를 자동 추정하는 기능. 강도는 분석가가 근거와 함께 넣습니다.
- 브랜드 카드가 파워트레인 비중까지 움직이는 교차 효과(중첩 로짓 포함값).
- 서버 저장, 다중 사용자 공유. 작업 파일(.json)을 주고받습니다.
- 디스플레이 가정(대당 수, 공급 비중)의 시간 변화. 지금은 기간 내내 같은 값입니다.
- 동력원별 대당 디스플레이 수 차이 (전기차가 더 많은 경우 등). 필요하면 브랜드 x 지역 행으로 근사합니다.
- 디스플레이 사업 실적 시스템과 직접 연동. 결과 CSV 형식(5.1)까지만 고정합니다.

## 9. 합격 기준

`tests/index.html` (또는 `node tests/run.cjs`) 의 23개 테스트가 전부 통과해야 합니다. 요지는 아래와 같습니다.

- [ ] 카드가 없으면 결과가 기준선과 같다
- [ ] 모든 지역, 모든 달에서 점유율 합과 파워트레인 비중 합이 1
