# 사내 모델에 넘기는 프롬프트

사내 모델(ChatGPT Enterprise, Cline + Qwen)은 이 도구의 계산 방식과 폐쇄망 제약을 모릅니다.
"시뮬레이터 고쳐 줘" 라고만 하면 점유율 합이 깨지는 식을 쓰거나 외부 라이브러리를 끌어옵니다.
여기 프롬프트는 이미 정해진 것과 합격 기준을 먼저 알려 줍니다.

| 파일 | 언제 |
| --- | --- |
| `00-project-instructions.md` | 처음 한 번. ChatGPT 프로젝트 지침에 붙여 넣습니다 |
| `10-column-names.md` | 사내 CSV 열 이름이 자동으로 안 잡힐 때 |
| `20-screen-change.md` | 결과 탭이나 보고서에 표, 지표, 차트를 더할 때 |
| `30-new-preset.md` | 자주 쓰는 카드(사내 표준 정책 카드)를 예시 목록에 더할 때 |
| `40-fix-error.md` | 테스트 실패, 콘솔 오류가 났을 때 |

## ChatGPT Enterprise

1. 프로젝트를 만들고 지침(Instructions)에 `00-project-instructions.md` 의 코드 블록을 붙여 넣습니다.
2. 프로젝트 파일로 `SPEC.md`, `types/sim.d.ts`, `types/app.d.ts` 를 올립니다.
3. 대화마다 10~40 중 하나를 골라 빈칸(〈 〉)을 채워 붙여 넣고, 고칠 파일 전체를 같이 붙여 넣습니다.

## Cline

10~40 의 본문을 그대로 붙여 넣습니다. 파일은 Cline 이 직접 엽니다.

## 공통 요령

- 한 번에 파일 하나. 여러 파일을 한꺼번에 시키면 앞 파일 내용을 잊고 서로 안 맞는 코드를 줍니다.
- `src/model/` 을 고쳤으면 `tests/index.html` 을 열어 23개가 전부 통과하는지 봅니다.
- 실제 판매 데이터와 브랜드 이름은 사내 모델에게만 줍니다. 바깥 저장소와 외부 서비스에는 올리지 않습니다.
