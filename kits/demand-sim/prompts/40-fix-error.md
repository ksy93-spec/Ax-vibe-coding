# 오류 고치기

오류 문구와 위치를 그대로 붙입니다. 추측을 덧붙이지 않는 편이 결과가 좋습니다.
사내 데이터 값, 브랜드 이름이 오류 문구에 섞여 있으면 바깥 저장소로 넘길 때는 지웁니다.

```
아래 오류를 고친다. 프로젝트 지침의 규칙을 따른다.

[어디서]
〈tests/index.html 의 실패 항목 이름 / 콘솔 오류 / 어떤 탭에서 무엇을 눌렀을 때〉

[오류 문구 그대로]
〈붙여 넣기〉

[최근에 바꾼 파일]
〈예: src/ui/view-result.js (아래에 전체 붙임)〉

할 일:
- 원인을 한두 줄로 말하고, 고칠 파일 하나를 전체로 준다.
- 테스트가 실패했으면 테스트가 아니라 코드를 고친다. 테스트 기대값을 바꾸지 않는다.
- 원인이 src/lib/ 나 types/ 에 있다고 보이면 코드를 쓰지 말고 그렇게 말한다.

완료 기준:
- tests/index.html 19/19 통과, 콘솔 오류 없음
```
