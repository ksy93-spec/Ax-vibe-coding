# 화면 바꾸기

단추를 더하거나 화면 문구, 배치를 바꿀 때 씁니다. 보통 `index.html` 하나, 동작까지 바꾸면 그다음에 `src/app.js` 하나를 따로 시킵니다.
CSS 가 필요하면 마지막에 `assets/css/memo.css` 를 따로 시킵니다.

```
아래 화면 변경을 한다. 프로젝트 지침의 규칙을 따른다.

[무엇을]
〈예: 메모장 위쪽 단추 줄에 "오늘 날짜 넣기" 단추를 더한다. 누르면 커서 자리에 "10월 8일 목요일" 을 넣는다〉

[이번에 고칠 파일 하나]
〈index.html / src/app.js / assets/css/memo.css 중 하나. 아래에 전체 붙임〉

[이미 있는 것, 그대로 쓸 것]
- 날짜 글: App.core.clockText(new Date()).date
- 단추 모양: class="btn" (주요 동작은 "btn btn-primary", 지우는 동작은 "btn btn-danger")
- 확인 창: await ask('물을 말', '예 단추 글'), 알림 글: toast('말')
- 저장: 상태를 바꾼 뒤 save() (곧바로 저장해야 하면 saveNow())

할 일:
- 위 파일 하나만 고쳐 전체를 준다.
- 다른 파일도 고쳐야 하면 코드를 쓰지 말고 어느 파일에 무엇이 필요한지만 말한다.

완료 기준:
- index.html 을 열어 새 단추가 다른 단추와 같은 크기로 보인다
- 화면 색 세 가지(흰 바탕, 검은 바탕, 누런 바탕) 모두에서 글씨가 잘 보인다
- 콘솔(F12)에 오류가 없고, tests/index.html 이 전부 통과한다
```
