# big-memo

큰 글씨 메모장. 청력이 많이 약한 어르신이 쓰거나, 어르신과 글로 대화할 때 쓰는 HTML 도구입니다.
`open-app.bat` 으로 열면 주소창 없는 창으로 떠서 PC 프로그램처럼 보입니다. exe 프로그램은 아닙니다.

## 실행 환경

- Node: 불필요 (선택: `node tests/run.cjs` 로 테스트할 때 18 이상, 바깥에서는 22.22.0 으로 확인)
- Python: 불필요
- 브라우저: Edge 또는 Chrome (Chromium 105 이상). `file://` 로 직접 열립니다.
- 빌드 단계: 없음

## 반입 방식

C. npm 의존성이 0개입니다. 반입되는 것은 소스 텍스트, 글꼴 파일, 아이콘 그림뿐입니다.

## 포함된 의존성

npm 패키지 없음. 아래는 코드가 아닌 자산입니다.

| 파일 | 출처 | 버전 | 라이선스(SPDX) | 원문 |
| --- | --- | --- | --- | --- |
| `assets/fonts/pretendard/` (woff2 92개, font.css) | Pretendard (Kil Hyung-jin), npm `pretendard@1.3.9` 의 공식 가변 분할 파일. `shared/fonts/pretendard` 와 같은 파일 | 1.3.9 원본 그대로 | OFL-1.1 | `assets/fonts/pretendard/LICENSE.txt` |
| `assets/icon.ico` `assets/icon.png` | 이 저장소에서 만든 그림. 노란 바탕에 Pretendard 로 쓴 "가" 한 글자를 그림으로 찍은 것 | - | 저장소 자체 저작물 | - |

글꼴 파일은 고치지 않았습니다. 아이콘은 글꼴로 쓴 글자를 그림으로 찍은 결과물이라 OFL 의 글꼴 수정에 해당하지 않습니다.
나머지 코드는 전부 이 저장소에서 작성했습니다.

## 기능

| 화면 | 할 수 있는 것 |
| --- | --- |
| 메모장 | 40px 기본 글씨(24~72px 6단계), 쓰는 대로 자동 저장, 첫 줄이 제목, 찾기, 위에 고정, 인쇄(24pt), 글 파일(.txt) 저장, 지운 메모 30일 보관과 되살리기 |
| 크게 보여주기 | 메모 전체나 고른 글만 화면 가득. 글씨 크기는 화면에 맞춰 자동으로 정해집니다. F2 로 열고 Esc 로 닫습니다 |
| 대화하기 | 상대가 아래 칸에 쓰는 동안 위에 아주 크게 나옵니다. Enter 로 보내면 지난 대화에 쌓이고, 지난 대화를 누르면 화면 가득 다시 보여줍니다. 자주 쓰는 말 단추(12개 기본, 고칠 수 있음), 대화를 메모로 남기기 |
| 알림 | 정한 시각(매일 또는 한 번)이나 5분/10분/30분/1시간 뒤. 시각이 되면 화면 전체가 1초마다 노랑과 검정으로 바뀌며 글이 크게 나옵니다. 창 제목도 깜빡이고, 원하면 낮은 음(500Hz) 소리를 같이 냅니다. "5분 뒤 다시" 가 있습니다 |
| 공통 | 날짜, 요일, 시각을 머리글에 크게 표시. 화면 색 3가지(흰 바탕, 검은 바탕 노란 글씨, 누런 바탕), 글씨 굵기, 백업 파일 만들기와 불러오기 |

청력이 약한 분을 위한 결정:

- 소리에 기대는 피드백이 없습니다. 저장, 지우기, 알림 결과는 모두 화면 아래 큰 글 상자로 알립니다.
- 세 가지 색 조합 모두 글자와 바탕의 대비가 7.8:1 이상(WCAG AAA 기준 7:1)입니다. 단추, 경고, 알림 화면 색도 같은 기준으로 계산해 확인했습니다.
- 알림의 깜빡임은 1초에 한 번입니다. 초당 3번을 넘는 깜빡임은 광과민성 발작 위험이 있어 쓰지 않습니다. 윈도의 "애니메이션 표시" 를 끈 PC 에서는 깜빡이지 않고 노란 화면으로만 나옵니다.
- 알림 소리는 노인성 난청에서 상대적으로 잘 들리는 낮은 음으로 냈습니다.
- 지우기는 항상 확인을 묻고, 지운 메모는 30일 동안 되살릴 수 있습니다. 확인 창의 기본 단추는 "그만두기" 입니다.
- 대화하기에서 한글을 조합하는 중에 누른 Enter 는 보내기로 치지 않습니다.

넣지 않은 것:

- 말을 글자로 바꾸는 받아쓰기. 브라우저의 음성 인식(Web Speech API)은 Google, Microsoft 서버로 소리를 보내야 해서 인터넷이 없는 사내에서 동작하지 않습니다.
- 창이 꺼져 있을 때의 알림. 이 도구는 열려 있는 동안만 알림을 냅니다. 꺼져 있던 동안 지난 알림은 다음에 열 때 "놓친 알림" 으로 한 번 나옵니다.

## 구성

| 경로 | 내용 | 사내에서 수정 |
| --- | --- | --- |
| `index.html` | 화면 뼈대. 스크립트는 `src/core.js` 다음 `src/app.js` | 단추를 더할 때만 |
| `src/core.js` | 날짜 글, 메모 정렬과 찾기, 알림 시각 계산, 저장값 검사. DOM 을 쓰지 않습니다 | 테스트를 먼저 고친 뒤 |
| `src/app.js` | 화면, 저장(localStorage `big-memo.v1`), 알림 화면, 소리 | 예 |
| `assets/css/memo.css` | 스타일. 색은 맨 위 `:root` 와 테마 블록의 변수만 씁니다 | 예 |
| `open-app.bat` `open-app.ps1` | Edge(없으면 Chrome)를 앱 창으로 띄워 `index.html` 을 엽니다 | 아니오 |
| `make-shortcut.bat` `make-shortcut.ps1` | 바탕화면에 "큰 글씨 메모장" 바로가기(아이콘 포함)를 만듭니다 | 아니오 |
| `tests/` | `src/core.js` 합격 기준 19개. `node tests/run.cjs` 또는 `tests/index.html` | 테스트를 지우지 말 것 |
| `types/memo.d.ts` | 저장 모양과 `App.core` API | 아니오 |
| `prompts/` | 사내 모델에 붙여 넣을 프롬프트 | 예 |
