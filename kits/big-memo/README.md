# 큰 글씨 메모장

청력이 많이 약한 분이 휴대폰이나 태블릿에서 쓰는 메모장입니다. 개인용이며, 사내 반입 킷이 아닙니다.

주소: https://ksy93-spec.github.io/Ax-vibe-coding/ (GitHub Pages 를 켠 뒤부터 열립니다. 아래 "올리기")

## 할 수 있는 것

| 화면 | 기능 |
| --- | --- |
| 메모장 | 큰 글씨(24~72px, 휴대폰은 32px 로 시작), 쓰는 대로 자동 저장, 말로 쓰기(받아쓰기), 찾기, 위에 고정, 카카오톡/문자로 보내기, 지운 메모 30일 보관 |
| 크게 보여주기 | 메모나 고른 글을 화면 가득. "뒤집기" 를 누르면 글이 거꾸로 돌아가 맞은편에 앉은 사람이 읽기 좋습니다 |
| 대화하기 | "말 듣기 시작" 을 누르면 옆 사람이 하는 말이 글자로 바뀌어 아주 크게 나옵니다. 말이 끊겨도 "그만 듣기" 를 누를 때까지 계속 듣습니다. 글로 써서 보여주기, 자주 쓰는 말 단추, 지난 대화, 대화를 메모로 남기기 |
| 알림 | 매일 또는 한 번, 5분~1시간 뒤. 시각이 되면 화면 전체가 노랑과 검정으로 바뀌고 글이 크게 나옵니다. 원하면 소리와 떨림(안드로이드)도 같이 |
| 설정 | 화면 색 3가지, 글씨 굵기, 화면 켜 두기(대화할 때만 / 늘 / 안 함), 자주 쓰는 말 고치기, 백업 파일 만들기와 불러오기 |

휴대폰의 "뒤로" 단추를 누르면 크게 보여주기, 자주 쓰는 말 판, 메모 쓰는 칸이 차례로 닫힙니다.
한 번 연 뒤에는 인터넷이 없어도 열립니다. 받아쓰기만 인터넷이 필요합니다.

## 기기에 설치하기

- 안드로이드(갤럭시 탭 등): Chrome 으로 주소를 열고 오른쪽 위 ⋮ → "홈 화면에 추가" 또는 "앱 설치".
  삼성 인터넷은 받아쓰기가 안 될 수 있으니 Chrome 을 쓰세요.
- 아이패드, 아이폰: Safari 로 주소를 열고 공유 단추 → "홈 화면에 추가".
  홈 화면 아이콘으로 연 창과 Safari 는 메모를 따로 저장합니다. 한쪽으로만 쓰세요.
  받아쓰기가 홈 화면 아이콘에서 안 되면 Safari 에서 여세요.
- 처음 "말 듣기 시작" 을 누르면 마이크 허용을 묻습니다. "허용" 을 누릅니다.

## 알아 둘 것

- 메모는 그 기기의 브라우저 안에만 저장됩니다. 서버로 가지 않습니다. 기기를 바꾸거나 브라우저 기록을 지우기 전에 설정 → "백업 파일 만들기".
- 받아쓰기는 브라우저 기능(Google 또는 Apple 음성 인식)을 씁니다. 말소리가 그 회사 서버로 가서 글자로 바뀝니다.
- 알림은 이 화면이 켜져 있을 때만 울립니다. 휴대폰은 화면이 꺼지거나 다른 앱을 쓰면 브라우저가 멈추기 때문입니다.
  알림을 쓸 때는 태블릿을 충전기에 꽂고 설정에서 "늘 켜 두기" 를 고르세요. 꺼져 있던 동안 지난 알림은 다시 열 때 "놓친 알림" 으로 나옵니다.
  약 시간처럼 꼭 지켜야 하는 알림은 기기 자체의 알람도 같이 맞추세요.
- 알림 깜빡임은 1초에 한 번입니다. 초당 3번을 넘는 깜빡임은 광과민성 발작 위험이 있어 쓰지 않습니다.
- 세 가지 화면 색 모두 글자와 바탕의 대비가 7.8:1 이상입니다(WCAG AAA 기준 7:1).

## 올리기 (GitHub Pages)

이 폴더 내용을 `gh-pages` 브랜치 맨 위에 그대로 올려 두었습니다. 처음 한 번만 저장소에서 켭니다.

1. 저장소 Settings → Pages
2. Source: Deploy from a branch, Branch: `gh-pages` / `(root)` → Save
3. 1~2분 뒤 위 주소가 열립니다

고친 뒤 다시 올릴 때는 `src/app.js` 의 `APP_VERSION` 과 `sw.js` 의 `CACHE` 이름을 같이 올리고, 이 폴더를 `gh-pages` 에 다시 올립니다.
기기에서는 앱을 두 번 열면 새 판이 됩니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 화면 뼈대 |
| `src/core.js` | 날짜 글, 메모 정렬과 찾기, 알림 시각, 받아쓰기 결과 정리, 저장값 검사 (화면과 무관한 계산) |
| `src/app.js` | 화면, 저장(localStorage `big-memo.v1`), 받아쓰기, 알림, 화면 켜 두기 |
| `assets/css/memo.css` | 스타일. 색은 맨 위 변수만 |
| `manifest.webmanifest` `sw.js` `assets/icon-*.png` | 홈 화면 설치와 인터넷 없이 열기 |
| `assets/fonts/pretendard/` | Pretendard 1.3.9 원본 분할 파일 (OFL-1.1, `LICENSE.txt`) |
| `tests/` | `src/core.js` 테스트 21개. `node tests/run.cjs` 또는 `tests/index.html` |

## 확인한 것 (2026-10-08, 판 2026.10.09.2)

- `node tests/run.cjs` 21/21 통과, 브라우저 `tests/index.html` 도 같음
- 헤드리스 Chromium 으로 Pixel 7, iPad 가로/세로 크기를 흉내 내어 확인: 메모 쓰기와 저장, 뒤로 단추, 말로 쓰기, 보내기(복사),
  크게 보여주기와 뒤집기, 대화하기 받아쓰기(듣는 중 글 → 확정 글, 끊기면 다시 듣기), Enter 로 보내기, 자주 쓰는 말 판, 알림 울림,
  설정, 인터넷을 끊고 다시 열기(글꼴 포함), 받아쓰기가 없는 브라우저 안내. 콘솔 오류 0건
- 받아쓰기는 가짜 음성 인식으로 흐름만 확인했습니다. 실제 기기의 마이크와 Google/Apple 음성 인식으로는 아직 시험하지 못했습니다
