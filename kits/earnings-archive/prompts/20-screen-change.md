# 화면 바꾸기

표에 줄을 더하거나, 카드에 지표를 더하거나, 새 비교 차트를 넣을 때 씁니다. 고칠 파일 하나를 정해 전체를 같이 붙여 넣습니다.

| 바꾸고 싶은 곳 | 파일 |
| --- | --- |
| 한눈에 보기 카드, 비교 차트, 비교 표 | `src/ui/view-overview.js` |
| 회사별 분기 표, 차트, 콜 요약 보기 | `src/ui/view-company.js` |
| 분기 편집 화면 | `src/ui/view-edit.js` |
| 찾기 | `src/ui/view-search.js` |
| 관리 (저장, 묶음, CSV, 환율, 회사 목록) | `src/ui/view-admin.js` |
| 스타일 | `assets/css/ea.css` (변수만) |

```
아래 파일 하나만 고친다. 프로젝트 지침의 규칙을 따른다.

[고칠 파일]
〈예: src/ui/view-company.js (아래에 전체 붙임)〉

[바꿀 것]
〈예: 분기 표에 "순이익률" 줄을 영업이익률 아래에 더한다. 값은 App.ea.core.derive 결과의 netMargin.〉

[지킬 것]
- 금액은 App.f.musd, 비율은 App.f.pct 로 표기한다.
- 숫자 계산이 새로 필요하면 코드를 쓰지 말고 어떤 계산이 필요한지 먼저 말한다 (src/model/ 은 테스트가 있는 파일이라 따로 고친다).
- 새 CSS 클래스가 필요하면 클래스 이름과 규칙을 코드 뒤에 따로 적는다 (assets/css/ea.css 는 다음 요청에서 고친다).

완료 기준:
- 콘솔 오류 없음. 회사별, 한눈에 보기 화면이 그대로 열림
- 자료가 없는 회사에서도 오류 없이 "-" 로 표시
```
