# 콜 요약 -> 센티먼트 점수 JSON

자료 넣기 탭 5번에서 콜 요약을 검사하면 이 프롬프트가 채워져 나옵니다. 이미 콜 요약이 들어 있는 분기는
자료 넣기에서 회사와 분기만 고르면 저장된 요약으로 만들어 줍니다. 녹취록 원문이 아니라 1단계 요약을 넣기 때문에 길이 걱정이 없습니다.

점수는 요인 8개, 0~10점입니다. 종합 점수는 모델이 아니라 도구가 요인 점수의 가중 평균으로 계산합니다
(가중치는 `src/model/sentiment.js` 의 `WEIGHTS`, 지금은 모두 1).

| 요인 (factor) | 이름 | 보는 것 |
| --- | --- | --- |
| `volume` | 판매량 가이던스 | 판매, 인도, 생산 대수 전망 |
| `revenue` | 매출 가이던스 | 매출 전망, 성장률 |
| `profit` | 수익성 가이던스 | 영업이익률, EBIT, 이익 전망 |
| `capex` | 투자 가이던스 | 설비투자, 연구개발비, 현금흐름 전망. 투자 축소로 현금흐름이 좋아지면 높게 |
| `supply` | 공급망 | 부품 수급, 반도체, 생산 차질 |
| `materialsFx` | 원자재·환율 | 원자재 가격, 배터리 원가, 환율 영향 |
| `demandPrice` | 수요·가격 | 주문, 재고, 가격, 인센티브(할인) |
| `tariffPolicy` | 관세·정책 | 관세, 보조금, 배출 규제 |

| 자리 | 넣을 것 |
| --- | --- |
| `{{factors}}` | 위 표를 "- key: 이름 (보는 것)" 줄로 |
| `{{scale}}` | 아래 점수 눈금 |
| `{{prev}}` | 직전 분기 요인별 점수와 근거. 없으면 "없음 (이번이 첫 점수)" |
| `{{text}}` | 이번 분기 콜 요약 (총평, 가이던스, 하이라이트, Q&A) |
| 나머지 | `10-call-summary.md` 표와 같음 |

점수 눈금:

- 0~2: 크게 악화 (가이던스 큰 폭 하향이나 철회, 심각한 차질)
- 3~4: 악화 (소폭 하향, 범위 하단으로 좁힘, 부담 증가)
- 5: 중립 (유지, 변화 없음, 좋고 나쁨이 비슷함)
- 6~7: 개선 (소폭 상향, 범위 상단으로 좁힘, 부담 감소)
- 8~10: 크게 개선 (큰 폭 상향, 뚜렷한 호전)
- 언급 없음: score 를 null 로, direction 을 "언급 없음" 으로. 5 를 주지 않는다

## 템플릿

```text
너는 자동차 산업 실적 자료를 분석하는 애널리스트다.
아래 [이번 분기 콜 요약]은 {{companyName}} 의 {{periodLabel}} 실적 컨퍼런스콜을 정리한 것이다.
요인마다 경영진 발언의 톤을 0~10점으로 매겨 [출력 형식]의 JSON 하나만 답한다. JSON 앞뒤에 설명을 붙이지 않는다.

[요인] (factor 에는 왼쪽 영문 이름을 쓴다)
{{factors}}

[점수 눈금]
{{scale}}

[규칙]
- 직전 분기 점수가 있으면 그것과 비교해 나아졌는지 나빠졌는지를 기준으로 삼는다. 같은 내용이면 같은 점수를 준다.
- 가이던스를 올렸으면 6 이상, 내렸으면 4 이하, 유지했으면 5 근처로 준다.
- 점수는 정수. direction 은 상향, 유지, 하향, 언급 없음 중 하나.
- 점수마다 reason 에 근거를 한 문장으로, quote 에 요약에 있는 표현을 짧게 옮긴다.
- 요약에 없는 내용으로 점수를 매기지 않는다. 언급이 없으면 score 는 null, direction 은 "언급 없음".
- 한국어 개조식으로 쓴다. 대시(—), 이모지, 굵은 글씨를 쓰지 않는다.

[직전 분기 점수]
{{prev}}

[출력 형식]
{
  "company": "{{companyId}}",
  "period": "{{period}}",
  "summary": "이번 분기 경영진 톤을 한 문장으로",
  "scores": [
    { "factor": "volume", "score": 4, "direction": "하향", "reason": "중국 수요 부진으로 연간 판매 전망을 낮춤", "quote": "연간 판매 소폭 감소 전망" }
  ]
}

[이번 분기 콜 요약]
{{text}}
```

## 점수가 흔들릴 때

- 같은 요약으로 두 번 시켜 1점 넘게 차이 나는 요인이 있으면, 그 요인의 "보는 것" 설명이 모호한 것입니다. `src/model/sentiment.js` 의 `hint` 를 구체적으로 고칩니다.
- 사람이 보기에 틀린 점수는 회사별 화면 > 편집 > 센티먼트에서 고칩니다. 모델 점수는 그대로 남고 화면에는 고친 점수가 나옵니다.

이 문서의 템플릿과 `src/model/prompt.js` 는 같은 글이어야 합니다. 한쪽을 고치면 다른 쪽도 고치고 `node tests/run.cjs` 로 확인합니다.
