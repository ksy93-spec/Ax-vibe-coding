# 컨퍼런스콜 원문 -> 요약 JSON

평소에는 이 문서를 볼 일이 없습니다. 도구의 **자료 넣기** 탭이 아래 템플릿에 회사, 분기, 원문을 채워 프롬프트를 만들어 주고
"복사" 단추 하나로 가져갈 수 있습니다. 도구를 열 수 없을 때, 또는 템플릿을 고치고 싶을 때만 이 문서를 씁니다.

## 손으로 쓸 때 순서

1. 원문을 준비합니다. Yahoo Finance 의 실적 콜 녹취록(Earnings Call Transcript) 페이지나 회사 IR 의 녹취록을 텍스트로 복사해
   메모장에 붙여 둡니다. 사외망 PC 에서 복사한 글을 사내로 옮기는 절차는 사내 규정을 따릅니다.
2. 원문이 24,000자(영문 약 4,000단어)를 넘으면 둘로 나눕니다. "Question-and-Answer Session" 또는 사회자가 첫 질문자를
   부르는 줄 앞이 경계입니다. 그래도 길면 빈 줄에서 더 나눕니다.
3. 아래 템플릿을 복사해 `{{...}}` 자리를 채웁니다. 조각마다 `{{task}}` 에는 맞는 할 일 블록을 넣습니다.
4. ChatGPT Enterprise(또는 Qwen)에 붙여 넣고, 답으로 온 JSON 을 도구의 **자료 넣기 > 3. 답 붙여 넣기** 칸에 붙여 넣습니다.
   조각이 여럿이면 조각마다 답을 하나씩 붙여 넣습니다. 도구가 합칩니다.

| 자리 | 넣을 것 | 예 |
| --- | --- | --- |
| `{{companyName}}` | 회사 이름 | General Motors (제너럴모터스) |
| `{{companyId}}` | 회사 id (관리 탭 회사 목록의 id) | gm |
| `{{period}}` | 달력 분기 | 2026Q3 |
| `{{periodLabel}}` | 분기 읽는 이름 | 2026 Q3 (7~9월) |
| `{{fiscalLabel}}` | 회사 회계연도 표기 | Q3 2026, FY2027 Q2 |
| `{{currency}}` | 발표 통화 | USD |
| `{{topics}}` | 주제 목록 | 실적, 가이던스, 전동화, 관세·정책, SDV·전장, 지역, 공급망·원가, 주주환원, 기타 |
| `{{partInfo}}` | 조각이 여럿일 때 "원문이 길어 N개 조각으로 나눴고, 이것은 K번째 조각이다." 하나면 비움 | |
| `{{task}}` | 아래 할 일 블록 중 하나 | |
| `{{text}}` | 원문 (조각) | |

## 템플릿

```text
너는 자동차 산업 실적 자료를 정리하는 애널리스트다.
아래 [원문]은 {{companyName}} 의 {{periodLabel}} 실적 컨퍼런스콜 녹취록이다. {{partInfo}}
원문을 읽고 [출력 형식]의 JSON 하나만 답한다. JSON 앞뒤에 설명을 붙이지 않는다.

[정해진 값]
- company: "{{companyId}}"
- period: "{{period}}" (달력 분기. 회사 표기로는 {{fiscalLabel}})
- 발표 통화: {{currency}}

[할 일]
{{task}}

[규칙]
- 원문에 없는 내용, 숫자, 사람 이름을 만들지 않는다. 확실하지 않으면 뺀다.
- 한국어 개조식으로 쓴다. 문장 끝은 "~함", "~임", "~ 전망", "~ 계획" 같은 명사형으로 끝낸다.
- 숫자는 원문의 통화와 단위를 그대로 쓴다. 예: "EBIT-adjusted 41억 달러", "영업이익 1조 2,000억 엔". 환율 환산을 하지 않는다.
- topic 은 다음 중 하나만 쓴다: {{topics}}
- 대시(—), 이모지, 굵은 글씨(**)를 쓰지 않는다.
- 원문 문장을 길게 옮기지 않고 요약한다. 꼭 필요할 때만 짧게 큰따옴표로 인용한다.
- 사람 이름과 회사 이름은 원문 철자(영문)를 그대로 쓴다.

[출력 형식]
{
  "company": "{{companyId}}",
  "period": "{{period}}",
  "callDate": "YYYY-MM-DD (원문에 있으면)",
  "summary": "이번 분기 총평 1~2문장",
  "highlights": [ { "topic": "실적", "text": "북미 픽업 판매 호조로 영업이익률 8.1% 기록함" } ],
  "guidance": "회사가 밝힌 연간 또는 다음 분기 전망. 숫자 그대로. 없으면 빈 문자열",
  "qa": [ { "asker": "질문자 이름", "firm": "소속 증권사", "question": "질문 요약", "answerer": "답변자 이름, 직책", "answer": "답변 요약", "topic": "가이던스" } ]
}

[원문]
{{text}}
```

## {{task}} 전체

원문을 나누지 않았을 때.

```text
- summary: 이번 분기 총평 1~2문장
- highlights: 경영진 발표의 요점 6~10개. 실적 숫자, 가이던스 변경, 지역별 흐름, 전동화, 관세와 정책, 원가, 주주환원 순으로 찾는다.
- guidance: 회사가 밝힌 전망 숫자. 없으면 빈 문자열
- qa: 애널리스트 질문 하나마다 항목 하나. 질문과 답변을 각각 1~3문장으로 요약한다. 사회자 안내와 인사말은 뺀다.
```

## {{task}} 발표 조각

```text
- 이 조각은 경영진 발표 부분이다.
- summary: 이번 분기 총평 1~2문장
- highlights: 요점 6~10개. 실적 숫자, 가이던스 변경, 지역별 흐름, 전동화, 관세와 정책, 원가, 주주환원 순으로 찾는다.
- guidance: 회사가 밝힌 전망 숫자. 없으면 빈 문자열
- qa: 빈 배열 []
```

## {{task}} 질의응답 조각

```text
- 이 조각은 질의응답 부분이다.
- qa: 애널리스트 질문 하나마다 항목 하나. 질문과 답변을 각각 1~3문장으로 요약한다. 사회자 안내와 인사말은 뺀다.
- 조각 첫머리에 앞 조각에서 이어지는 답변만 있고 질문이 없으면 그 부분은 뺀다.
- summary 와 guidance 는 빈 문자열, highlights 는 빈 배열 []
```

## 답이 이상할 때

- JSON 앞뒤에 설명이 붙거나 ```json 울타리가 있어도 도구가 걷어냅니다. 마지막 쉼표, 둥근 따옴표도 고쳐서 읽습니다.
- "닫는 } 를 찾지 못했습니다" 가 나오면 답이 길어서 끊긴 것입니다. 원문을 더 작게 나눠 다시 시킵니다(도구의 "조각 최대 글자 수" 를 줄입니다).
- 주제(topic)가 목록에 없으면 도구가 "기타" 로 넣고 경고를 띄웁니다. 저장 전에 미리보기에서 고칠 수 있습니다.
- 숫자를 원문과 대조하지 않고 저장하지 않습니다. 저장된 분기는 상태가 "검증 필요" 로 남고, 대조한 사람이 편집 화면에서 "확인" 으로 바꿉니다.

이 문서의 템플릿과 `src/model/prompt.js` 는 같은 글이어야 합니다. 한쪽을 고치면 다른 쪽도 고치고 `node tests/run.cjs` 로 확인합니다.
