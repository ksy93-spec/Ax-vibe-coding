# 주요 고객 실적 자료 명세

주요 고객(완성차 13곳, 부품사 4곳)의 분기 실적 숫자와 실적 컨퍼런스콜 요약(하이라이트, 가이던스, Q&A)을 분기마다 쌓아 두고 찾아보는 HTML 도구.
폐쇄망 사내 PC 에서 `index.html` 을 더블클릭해 엽니다.

## 1. 대상 회사

| 구분 | 회사 (id) |
| --- | --- |
| 완성차 | GM (gm), Tesla (tesla), 현대자동차 (hyundai), 기아 (kia), Toyota (toyota), Honda (honda), Mercedes-Benz (mercedes), BMW (bmw), Volkswagen (vw), Audi (audi), Porsche AG (porsche), JLR (jlr), Volvo Cars (volvo) |
| 부품사 | AUMOVIO (aumovio), DENSO (denso), ALPS ALPINE (alps), Visteon (visteon) |

회사는 관리 탭에서 더하고 고칩니다. id 는 파일 이름이 되므로 만든 뒤 바꾸지 않습니다.

## 2. 숫자와 단위

보는 지표는 넷입니다: **매출, 영업이익, 영업이익률, 부채비율**.

- 저장: 금액은 **발표 통화 백만 단위**, 원문에 적힌 부채비율은 % 숫자. 원문 표기(`raw`)를 같이 남깁니다.
- 화면: 매출과 영업이익은 **백만 달러(MUSD)**. 그 분기의 평균 환율(관리 탭 환율 표, 1 USD 당 통화 단위)로 나눕니다.
  분기 하나만 다른 환율을 써야 하면 편집 화면의 "이 분기만 쓸 환율" 에 넣습니다.
- 환율이 없으면 그 칸은 비우고 "환율 없음" 을 띄웁니다. 추정 환율로 채우지 않습니다.
- 전년 동기 대비(YoY)는 **발표 통화 기준**으로 계산합니다. 달러로 비교하면 환율 변동이 성장률에 섞이기 때문입니다.
- 영업이익률 = 영업이익 / 매출 (발표 통화 기준, 환율과 무관).
- 부채비율 = 분기 말 연결 부채총계 / 자본총계 x 100 (비지배지분 포함 자본). 부채나 자본이 없으면 원문에 적힌 비율을 쓰고 화면에 * 를 붙입니다.
  자본이 0 이하(자본잠식)면 계산하지 않습니다. 금융 자회사를 연결하는 회사(GM, Toyota, Mercedes 등)는 부채비율이 높게 나오므로 회사끼리보다 같은 회사의 추이로 봅니다.
- 영업이익률과 부채비율의 전년 대비는 %p 차이로 보여 줍니다.
- 분기는 **달력 분기**로 맞춥니다. 3월 결산 회사(토요타, 혼다, 덴소, 알프스알파인, JLR)의 4~6월은 2026Q2 이고,
  회사 표기(`fiscalLabel`, 예: FY2027 Q1)는 따로 남깁니다. 그래야 같은 달끼리 비교됩니다.
- 누계만 발표하는 회사는 숫자 답에 `basis: "ytd"` 로 오고, 도구가 같은 회계연도 앞 분기 값을 빼서 분기 값을 만듭니다. 매출, 영업이익만 해당하고 부채, 자본은 분기 말 잔액이라 그대로 씁니다.

| 지표 (key) | 뜻 |
| --- | --- |
| revenue | 매출 (분기) |
| operatingIncome | 회사가 공시하는 영업이익 (EBIT, Operating result 등. 조정 값이 아님. 회사 목록의 "영업이익 이름" 에 적음) |
| totalLiabilities | 분기 말 연결 부채총계 |
| totalEquity | 분기 말 연결 자본총계 |
| debtRatio | 원문에 적힌 부채비율(%). 부채총계, 자본총계가 없을 때만 씀 |

## 3. 화면

| 탭 | 하는 일 |
| --- | --- |
| 한눈에 보기 | 고른 분기의 회사 카드(매출, 영업이익, 영업이익률, 부채비율, 전년 대비), 세 지표 비교 막대, 표로 보기 |
| 회사별 | 최근 8분기 표, 매출, 영업이익률, 부채비율 막대, 고른 분기의 총평, 주제별 하이라이트, 가이던스, Q&A, 원문 보기. 편집, 삭제, 분기 추가 |
| 자료 넣기 | 1 회사와 분기, 2 원문(녹취록, 보도자료), 3 프롬프트 복사, 4 모델 답 붙여 넣기, 5 검사와 넣기 |
| 찾기 | 모든 회사의 하이라이트, 가이던스, Q&A 에서 낱말과 주제로 찾기 |
| 관리 | 파일로 저장, 자료 묶음 주고받기, CSV 내보내기, 환율 표, 회사 목록과 로고 |

## 4. 원문에서 페이지까지

```
 녹취록(Yahoo Finance 등) ─┐
                         ├─ 자료 넣기 2 ─> 3 프롬프트(조각별) ─> 사내 모델 ─> 4 답(JSON) ─> 5 검사 ─> 분기 자료
 보도자료 요약표 ─────────┘                 (숫자 프롬프트)
```

- 원문이 `maxChars`(기본 24,000자)보다 길면 발표와 질의응답으로 나누고 다시 글자 수로 자릅니다. 조각마다 프롬프트 하나, 답 하나.
- 사내 모델 답은 앞뒤 설명, ``` 울타리, 마지막 쉼표, 둥근 따옴표가 있어도 읽습니다. 그래도 안 되면 몇째 줄에서 막혔는지 보여 줍니다.
- 주제가 목록에 없으면 "기타" 로 넣고 경고합니다. 회사나 분기가 고른 것과 다르면 넣지 않습니다(분기는 고른 쪽으로 맞추고 경고).
- 넣은 분기는 상태가 "검증 필요" 입니다. 원문과 숫자를 대조한 사람이 편집에서 "확인" 으로 바꿉니다.
- 원문을 보관하면 `data/transcripts/<id>.js` 에 따로 저장하고, 화면에서 "원문 보기" 를 누를 때만 읽습니다.

## 5. 저장

- 자료 파일은 `data/` 아래 `.js` 입니다(file:// 에서 JSON 을 못 읽어서). 안쪽은 순수 JSON 입니다.
- 화면에서 고친 내용은 먼저 이 브라우저(localStorage)에 작업본으로 남고, 머리글에 "파일로 저장 안 됨 N" 이 뜹니다.
- 관리 탭에서 data 폴더를 연결하면(Chrome, Edge 의 폴더 쓰기 기능) 파일에 바로 씁니다. 연결이 안 되면 파일을 내려받아 data 폴더에 덮어씁니다.
- 파일마다 `rev` 가 있어, 덮어쓴 파일이 작업본을 따라오면 작업본은 저절로 지워집니다.
- 킷을 공유 폴더에 두면 여러 사람이 같은 자료를 봅니다. 저장은 한 사람(담당자)이 하는 것을 전제로 합니다. 두 사람이 같은 회사 파일을 동시에 고치면 나중에 저장한 쪽이 남습니다.

## 6. 바깥에서 사내로 보내는 자료 (업데이트 구조)

- 바깥(인터넷 되는 곳)에서 정리한 숫자와 요약은 `ea-pack-YYYYMMDD.json` 묶음으로 만들어 업데이트 zip 의 `packs/` 에 넣습니다.
- 사내에서는 관리 탭 "가져올 파일 고르기" 로 묶음을 읽습니다. 없는 분기는 추가, 사내에서 고친 분기는 남김(바꿀 수 있음), 바깥 자료끼리는 바꿈.
  환율은 빈 칸만 채웁니다.
- 업데이트 zip 은 `data/` 파일을 덮어쓰지 않습니다. 사내에서 쌓은 자료를 지키기 위해서입니다.

## 7. 하지 않을 것

- 인터넷에서 자료를 자동으로 받아오기 (폐쇄망)
- 녹취록 원문을 바깥 저장소에 담기 (저작권). 원문은 사내에서 붙여 넣고 사내 data 폴더에만 둡니다.
- 사내 모델에게 단위, 환율 환산 시키기
- 확인 안 된 숫자를 "확인" 상태로 넣기
- 두 지표를 한 차트에 겹친 이중 축 차트
