# 설치와 실행

설치할 것이 없습니다. 인터넷도 필요 없습니다.

## 1. 압축 해제

한글과 공백이 없는 짧은 경로에 풉니다. 예: `C:\work\earnings-archive`
여러 사람이 같이 보려면 팀 공유 폴더에 둡니다. 예: `\\share\mi\earnings-archive`

## 2. 실행

`index.html` 을 Chrome 이나 Edge 로 엽니다(더블클릭). 첫 판은 자료가 비어 있고 회사 17곳의 카드만 보입니다.

## 3. 처음 할 일

1. 관리 탭 > 환율: 쌓을 분기의 분기 평균 환율(1 USD 당 EUR, JPY, KRW, GBP, SEK)을 넣고 "환율 저장".
   사내에서 쓰는 기준 환율(재무팀 공시 환율 등)이 있으면 그것을 씁니다. 출처 칸에 적어 둡니다.
2. 관리 탭 > 회사 목록: 로고가 없는 6곳(Mercedes-Benz, JLR, AUMOVIO, DENSO, ALPS ALPINE, Visteon)은 "고치기 > 로고 바꾸기" 로 CI 파일을 넣습니다.
3. 관리 탭 > 파일로 저장: "data 폴더 연결" 을 누르고 킷 안의 `data` 폴더를 고릅니다. 이후 "폴더에 모두 저장" 한 번이면 파일에 반영됩니다.
   연결 단추가 없거나 회사 정책으로 막히면 "모두 내려받기" 로 받은 파일을 안내 창의 위치에 덮어씁니다.
4. 자료 넣기 탭에서 첫 회사를 넣어 봅니다. 연습은 `tests/fixtures/sample-transcript.txt` (가상 회사)와 `tests/fixtures/sample-answers.md` 로 합니다.
   연습한 분기는 회사별 화면에서 지우거나, 관리 탭에서 "되돌리기" 를 누릅니다.

## 4. 확인

- [ ] `tests/index.html` 을 열면 "36/36 통과" 가 나온다
- [ ] 글꼴이 맑은 고딕이 아니라 Pretendard 로 보인다
- [ ] 한눈에 보기에 회사 카드 17개가 나오고, 11곳은 CI 마크, 6곳은 글자 마크다
- [ ] 자료 넣기에서 연습용 녹취록을 넣고 "프롬프트 만들기" 를 누르면 프롬프트와 "복사" 단추가 나온다
- [ ] 연습용 답을 붙여 넣고 "검사" 를 누르면 초록 표시와 미리보기(하이라이트 7개, Q&A 5건)가 나온다
- [ ] 관리 탭에 "data 폴더 연결" 단추가 보인다 (없으면 내려받기로 저장)
- [ ] 브라우저 콘솔(F12)에 빨간 오류가 없다

## 문제가 생기면

**화면이 "자료를 읽는 중..." 에서 멈추거나 비어 있다**
`data/*.js` 하나의 JSON 문법이 깨졌을 가능성이 큽니다. F12 콘솔에 파일 이름과 줄 번호가 나옵니다. 손으로 고친 파일이면 쉼표와 따옴표를 봅니다.

**저장했는데 다른 사람 화면에 안 나온다**
머리글에 "파일로 저장 안 됨" 이 남아 있으면 아직 작업본입니다. 관리 탭에서 폴더에 저장하거나 내려받은 파일을 data 폴더에 덮어씁니다.
다른 사람은 새로 고침(F5)을 해야 보입니다.

**금액이 "-" 이고 "환율 없음" 이 뜬다**
그 분기의 환율이 없습니다. 관리 탭 환율 표에 넣습니다.

**모델 답 검사에서 "JSON 문법 오류"**
오류 문장을 그대로 모델에게 주고 "JSON 전체를 다시 줘" 라고 합니다. 답이 끊긴 경우면 "조각 최대 글자 수" 를 줄입니다.

**브라우저 저장 공간이 찼다는 알림**
원문을 많이 보관하면 생깁니다. 바로 관리 탭에서 파일로 저장하면 작업본이 비워집니다.
