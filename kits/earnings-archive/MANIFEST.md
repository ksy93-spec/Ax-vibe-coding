# earnings-archive

주요 고객 실적 자료. 완성차 13곳(GM, Tesla, 현대자동차, 기아, Toyota, Honda, Mercedes-Benz, BMW, Volkswagen, Audi, Porsche, JLR, Volvo Cars)과
부품사 4곳(AUMOVIO, DENSO, ALPS ALPINE, Visteon)의 분기 실적(매출, 영업이익, 영업이익률, 부채비율)과 실적 컨퍼런스콜 하이라이트, 가이던스, Q&A 를
쌓아 두는 HTML 도구입니다. 매출과 영업이익은 백만 달러(MUSD)로 보여 줍니다. 녹취록을 붙여 넣으면 사내 모델용 프롬프트가 나오고, 모델 답(JSON)을 붙여 넣으면 검사해서 페이지에 넣습니다.
설계는 `SPEC.md`, 자료 구조는 `types/ea.d.ts` 에 있습니다. 사내 ChatGPT Enterprise 로 고칠 때는 `READMEChatGPT.md` 부터 봅니다.

## 실행 환경

- Node: 불필요 (선택: `node tests/run.cjs` 로 테스트할 때 18 이상, 바깥에서는 22.22.0 으로 확인)
- Python: 불필요
- 브라우저: Chrome, Edge (Chromium 105 이상). `file://` 로 직접 열립니다. data 폴더에 바로 저장하는 기능은 Chromium 86 이상의 File System Access API 를 씁니다.
- 빌드 단계: 없음

## 반입 방식

C. npm 의존성이 0개입니다. 반입되는 것은 소스 텍스트, 글꼴 파일, SVG 로고뿐입니다.

## 들어 있는 자료

2026.10.23.2 판도 **실적 숫자와 콜 요약이 비어 있습니다.** 회사 목록 17곳, 빈 환율 표, 회사별 빈 자료 파일만 있습니다.

만들 때 각 회사 IR 사이트와 환율 출처(FRED, ECB, 한국은행)에서 공식 숫자를 받아 첫 자료로 넣으려 했으나,
작업한 바깥 환경의 네트워크 정책이 이 사이트들을 막아 원문을 확인하지 못했습니다. 확인 안 된 숫자는 넣지 않았습니다.
네트워크가 열린 바깥 세션에서 공식 자료로 묶음(`packs/ea-pack-*.json`)을 만들어 업데이트로 보내거나, 사내에서 자료 넣기로 채웁니다.

`tests/fixtures/` 의 녹취록과 답은 연습용 가상 자료입니다. 실제 회사 숫자가 아닙니다.

## 이 킷이 대신 해결해 둔 것

- 사내 모델이 가장 자주 틀리는 단위 환산을 맡기지 않습니다. 모델은 원문 숫자와 단위(billion, 조, 億円)를 옮기고, 도구가 백만 단위로 바꾼 뒤 원문 표기와 나란히 보여 줍니다.
- 녹취록이 길면 발표와 질의응답 경계에서 나누고 글자 수로 다시 잘라 조각별 프롬프트를 만듭니다. 조각별 답은 합치면서 겹친 문장을 뺍니다.
- 모델 답에 붙는 설명 문장, ``` 울타리, 마지막 쉼표, 둥근 따옴표를 걷어내고 읽습니다. 못 읽으면 줄과 글자 위치를 알려 줍니다.
- 3월 결산 회사를 달력 분기로 맞춰 같은 달끼리 비교하고, 회사 표기(FY2027 Q1)는 따로 남깁니다. 누계만 발표하면 앞 분기를 빼서 분기 값을 만듭니다.
- 전년 대비는 발표 통화 기준이라 환율 변동이 성장률에 섞이지 않습니다. MUSD 는 분기 평균 환율로, 분기별 예외 환율도 넣을 수 있습니다.
- 부채비율은 모델에게 계산시키지 않고 부채총계와 자본총계로 도구가 계산합니다. 원문에 비율만 있으면 그 값을 쓰고 * 로 구분합니다.
- file:// 에서 JSON 을 못 읽는 문제를 `.js` 자료 파일로 피했습니다. 화면에서 고친 내용은 data 폴더에 바로 쓰거나(폴더 연결) 내려받아 덮어씁니다.
- 판(rev) 번호로 "아직 파일에 없는 변경" 을 구분해 머리글에 띄우고, 파일이 따라오면 작업본을 저절로 비웁니다.
- 바깥 자료 묶음은 사내에서 고친 분기를 덮지 않고, 환율은 빈 칸만 채웁니다.
