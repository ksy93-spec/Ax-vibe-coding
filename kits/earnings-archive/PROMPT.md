# 사내 모델용 프롬프트

프롬프트는 `prompts/` 에 있습니다. 어떤 파일을 언제 쓰는지는 `prompts/README.md` 에 적었습니다.

- 매 분기 자료 만들기: 도구의 **자료 넣기** 탭이 프롬프트를 만들어 줍니다. 손으로 할 때는 `prompts/10-call-summary.md`, `prompts/11-numbers.md`.
- 도구 고치기: `READMEChatGPT.md` 를 먼저 읽습니다. ChatGPT 에 줄 설명 블록, 모듈 지도, 변경별 파일 순서가 있습니다. Cline 은 `.clinerules` 를 자동으로 읽습니다.
