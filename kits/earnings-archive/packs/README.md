# 자료 묶음

바깥(인터넷 되는 곳)에서 정리해 보내는 분기 숫자와 요약 묶음(`ea-pack-YYYYMMDD.json`)을 여기에 둡니다.
업데이트 zip 은 `data/` 를 덮어쓰지 않고 이 폴더에 묶음 파일만 더합니다. 사내에서 쌓은 자료를 지키기 위해서입니다.

가져오기: 도구의 관리 탭 > 자료 묶음 주고받기 > "가져올 파일 고르기" 에서 이 폴더의 파일을 고릅니다.
없는 분기는 추가하고, 사내에서 고친 분기는 남기는 것이 기본입니다. 표에서 분기마다 바꿀 수 있습니다.

지금은 묶음이 없습니다. 첫 판은 빈 자료로 시작합니다.
