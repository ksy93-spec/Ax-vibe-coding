# 자료 묶음

다른 사람이 내보낸 자료 묶음(`ea-pack-*.json`)을 두는 곳입니다. 관리 탭 > 자료 묶음 주고받기 > "가져올 파일 고르기" 로 넣습니다.
없는 분기는 추가하고, 사내에서 고친 분기는 남기는 것이 기본입니다. 환율은 빈 칸만 채웁니다.

바깥에서 모은 과거 실적은 2026.11.02.3 판부터 `data/reports/` 에 바로 들어 있어 따로 가져올 필요가 없습니다.

| 파일 | 내용 |
| --- | --- |
| `mercedes-2015q1-2026q2.csv` | Mercedes-Benz 2015 Q1 ~ 2026 Q2 분기 실적을 엑셀로 보는 표 (MUSD, 영업이익률, 부채비율) |

## Mercedes-Benz 자료 읽는 법

- 수치는 발표 당시 기준입니다. 2015~2021년은 트럭 사업(Daimler Truck)을 포함하므로 2022년부터와 바로 비교하지 않습니다.
- 2021 Q4 EBIT 14,557 에는 트럭 분사 일회성 이익(약 92억 유로)이 들어 있습니다.
- 부채비율은 분기 말 자본총계와 자산총계(부채 = 자산 - 자본)로 계산합니다. 연결 기준이라 금융 자회사 부채가 포함돼 수치가 높습니다.
  회사가 따로 밝히는 "자기자본비율" 은 이 계산과 1.2~1.5%p 어긋나 쓰지 않았습니다.
- 2019년부터 리스 회계(IFRS 16)로 부채가 늘었습니다.
